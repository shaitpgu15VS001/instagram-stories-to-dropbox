🛠️ מדריך התקנה - צעד אחר צעד

מדריך זה ילווה אותך בהתקנה הראשונית, מאפס ועד הרצה ראשונה.
זמן משוער: 30-45 דקות.

מדריכים: התקנה (קצר) שימוש מורחב פתרון בעיות

חלק 1: הכנה

לפני שמתחילים, צריך:

  • חשבון Dropbox או OneDrive (אפשר חינמי)
  • גישה למייל (לאימות GitHub וענן)
  • 30-45 דקות פנויות
  • מחשב עם Windows, Mac או Linux (רק להתקנה - אחר כך הכל רץ בענן)

חלק 2: חיבור אחסון ענן (rclone)

המערכת מתחברת לענן דרך כלי בשם rclone. כל החיבורים נשמרים בקובץ אחד: rclone.conf.

שלב 1: התקנת rclone

פתח PowerShell והרץ:

winget install rclone
אם winget לא מותקן, הורד מ-rclone.org/downloads והתקן ידנית.

שלב 2: חיבור ל-Dropbox

rclone authorize "dropbox"
  1. תיפתח הודעה עם קישור או קוד
  2. פתח את הקישור בדפדפן, התחבר ל-Dropbox ואשר גישה
  3. אחרי האישור יופיע token ב-PowerShell - אל תסגור את החלון

שלב 3: חיבור ל-OneDrive (אופציונלי)

rclone authorize "onedrive" --auth-no-open-browser
  1. העתק את הקישור לדפדפן, התחבר לחשבון Microsoft ואשר
  2. יופיע token ב-PowerShell

שלב 4: יצירת קובץ התצורה

rclone config

לכל חיבור (Dropbox / OneDrive): הקש n, תן שם (dropbox), בחר את הסוג מהרשימה, השאר Client Id/Secret ריקים, בחר N ב-auto config, הדבק את ה-token, ואשר עם y. בסיום הקש q.

שלב 5: העתקת התצורה

notepad "$env:USERPROFILE\.config\rclone\rclone.conf"

העתק את כל תוכן הקובץ. שמור אותו - תדביק אותו ב-GitHub בהמשך.

חלק 3: אחסון ברירת מחדל

אם חיברת יותר מענן אחד, קבע לאן יעלו הקבצים כברירת מחדל. ערוך את STORAGE_BACKEND.txt וכתוב שם אחד:

dropbox

או onedrive. אפשר גם לבחור ענן אחר בכל הרצה ידנית (ראה מדריך שימוש).

חלק 4: חשבון GitHub וריפו

  1. אם אין לך חשבון: github.com/signup - בחר תוכנית Free
  2. צור ריפו חדש: github.com/new - שם למשל instagram-stories-to-dropbox, בחר Private
  3. העלה את קבצי הפרויקט מהמחשב (ראה מדריך שימוש, חלק העלאה)

חלק 5: Secret יחיד

  1. בריפו: Settings ← Secrets and variables ← Actions ← New repository secret
  2. Name: RCLONE_CONF, תוכן: כל תוכן rclone.conf משלב 5
זה ה-Secret היחיד שהמערכת צריכה. הוא מכיל את כל חיבורי הענן.

חלק 6: משתמש ראשון והרצה ראשונה

  1. ערוך את usernames.txt בריפו והוסף שורה עם שם משתמש (בלי @), למשל natgeo
  2. עבור לטאב Actions ← בחר את ה-workflow ← Run workflow
  3. ההרצה הראשונה לוקחת 3-5 דקות (מתקינה דפדפן). עקוב בלוגים
  4. בדוק בענן: תיקייה Instagram/<תאריך>/<שם>/
חשוב: המערכת מורידה רק מחשבונות ציבוריים. חשבונות פרטיים לא נתמכים.
