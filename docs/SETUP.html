🛠️ מדריך התקנה קצר – מאפס עד סטורי ראשון בענן

מה המערכת עושה? רובוט חינמי שבודק כל כמה שעות סטוריז של אנשים שבחרת באינסטגרם, ושומר אותם אוטומטית בענן שלך (Dropbox או OneDrive). בלי חשבון אינסטגרם, בלי מחשב דולק, באנונימיות מלאה.

איך זה עובד? אינסטגרם ← שירות הורדה ← רובוט GitHub ← הענן שלך. אתה מגדיר פעם אחת, וזה רץ לבד.

זמן משוער: 30-45 דקות. צריך: חשבון ענן, כתובת מייל, מחשב.

מדריכים: התקנה (קצר) שימוש מורחב פתרון בעיות

שלב 1: מה זה GitHub ולמה צריך אותו?

GitHub הוא אתר שמאחסן קבצים ומריץ תוכנות בחינם, 24 שעות ביממה. הרובוט שלנו גר שם – המחשב שלך יכול להיות כבוי והכל ממשיך לעבוד. התוכנית החינמית מספיקה לגמרי.

פתיחת חשבון: היכנס ל-github.com/signup ← מלא מייל, סיסמה ושם משתמש ← אשר את המייל שישלחו לך ← בחר תוכנית Free. זהו, יש לך חשבון.

שלב 2: חיבור הענן (5 דקות + המתנה לאישור)

נתחבר ל-Dropbox בעזרת תוכנה קטנה בשם rclone (מתווך בין המחשב לענן).

1. פתח PowerShell (חפש "PowerShell" בתפריט התחל) והדבק: 
winget install rclone
לחץ Enter וחכה לסיום.
2. הדבק: 
rclone authorize "dropbox"
יופיע קישור – פתח אותו בדפדפן, התחבר ל-Dropbox ולחץ אישור (Allow). חזור ל-PowerShell – יופיע קוד ארוך (token). אל תסגור את החלון!
3. הדבק: 
rclone config
ענה כך: הקש n ← שם: dropbox ← בחר את המספר של Dropbox מהרשימה ← פעמיים Enter (ריק) ← N ← הדבק את הקוד מצעד 2 ← y ← בסוף q.
4. הדבק: 
notepad "$env:USERPROFILE\.config\rclone\rclone.conf"
ייפתח קובץ – העתק את כל תוכנו ושמור בצד (בקובץ טקסט זמני). זה המפתח לענן.
OneDrive? אפשר להוסיף אחר כך – ראה המדריך המורחב. כרגע מספיק ענן אחד.

שלב 3: יצירת מקום לפרויקט בגיטהאב

1. היכנס ל-github.com/new ← תן שם, למשל instagram-stories ← בחר Private (פרטי – רק אתה רואה) ← Create repository.
2. בדף הריפו לחץ Add file ← Upload files ← גרור את כל קבצי הפרויקט שקיבלת ← Commit changes (כפתור ירוק). הקבצים עולים לרשת.
קיבלת את הקבצים כקובץ ZIP? חלץ אותו קודם לתיקייה, ואז גרור את תוכן התיקייה (לא את התיקייה עצמה).

שלב 4: המפתח היחיד (Secret)

כדי שהרובוט יוכל להעלות לענן שלך, נותנים לו את המפתח משלב 2 – במקום מוצפן שנקרא Secret (אף אחד לא יכול לראות מה כתוב בו, גם לא אתה אחרי השמירה).

1. בריפו: Settings (למעלה) ← בתפריט השמאלי Secrets and variables ← Actions ← New repository secret.
2. בשם כתוב RCLONE_CONF, בתוכן הדבק את כל מה שהעתקת בשלב 2 צעד 4 ← Add secret. זהו – זה הסוד היחיד שצריך.
כלל ברזל: לעולם לא להעלות את קובץ rclone.conf עצמו לריפו – רק להדביק את תוכנו לתוך ה-Secret!

שלב 5: אדם ראשון למעקב

1. בריפו לחץ על usernames.txt ← סמל העיפרון ✏️ ← כתוב שם משתמש אחד (בלי @), למשל natgeo ← Commit changes.
חייב להיות חשבון ציבורי (רואים אותו בדפדפן בלי להתחבר). פרטי – לא יעבוד לעולם.

שלב 6: הרצה ראשונה ובדיקה 🎉

1. לחץ למעלה על Actions (אם כתוב שה-workflows כבויים – אשר).
2. בצד שמאל לחץ על Download Instagram Stories to Dropbox ← מימין Run workflow ← שוב Run workflow.
3. לחץ על ההרצה שנפתחה ← sync – רואים לוג חי. ההרצה הראשונה לוקחת 3-5 דקות (מתקינה דברים).
4. בסוף הלוג חפש RUN SUMMARY – אם יש שורת STORIES_FOUND, הצלחת! בדוק בענן: תיקייה Instagram ← תאריך היום ← שם המשתמש ← הקבצים.
אין קבצים? או שאין סטורי פעיל עכשיו (נמחק אחרי 24 שעות – תקין!), או שהחשבון פרטי. נסה חשבון פעיל מאוד כמו instagram. עזרה נוספת: פתרון בעיות.

סיימת! מה הלאה?

  • המערכת רצה לבד כל 3 שעות. להוספת אנשים – עוד שורות ב-usernames.txt.
  • לכל השאר (ענן שני, שמות בעברית, תדירות, דיוק, קריאת דו"חות) – המדריך המורחב.
